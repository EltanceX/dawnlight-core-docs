# 光影包设置 UI 开发者参考

本文描述当前 Manifest v3 光影包设置菜单的正式合同。设置 UI 只负责呈现和编辑 Manifest
option；程序、资源、Pass 和运行时生命周期仍遵循 Manifest 与可信 C# 注册边界。

## 1. 最小入口与加载决策

External Complete 光影包可在根 `shaderpack.json` 声明包内 UI 文件：

```json
{
  "manifestVersion": 3,
  "settings": "manifest/ui/settings.json"
}
```

组合式 Manifest 也只能在根声明 `settings`；fragment 只组合 `options`、`resources`、`passes`
和 `programs`。

| 根 `settings` | Manifest option | 结果 | `settingsSource` / UI hash |
|---|---:|---|---|
| 缺省 | 0 | `Empty`，没有光影包菜单页 | `<none>` / `<none>` |
| 缺省 | 大于 0 | `AutoGenerated`，按 option 顺序生成通用页 | `<none>` / `<none>` |
| 有效 JSON 路径 | 任意 | `Authored`，完全采用包定义的页面结构 | 规范化相对路径 / 64 个十六进制字符的 SHA-256 |
| 无效 JSON 路径或文档 | 任意 | 整个候选包加载失败 | 不生成 descriptor，不回退 Auto |

BuiltIn Minimal descriptor 不访问外部文件系统，使用共享 `Empty` schema。若最小包需要零额外纹理、
零扩展 Pass 和零设置，只需保持空的 option/resource/pass 数组。

## 2. 可运行示例

- Empty：`docs/examples/shader-pack-settings/empty/shaderpack.json`；
- Auto：`docs/examples/shader-pack-settings/auto/shaderpack.json`，覆盖 boolean、choice string、integer
  slider 和 number slider；
- 紧凑 Authored：`Survivalcraft.Pipeline.Tests/Fixtures/P9/SettingsUi/Valid/shaderpack.json` 及其
  `manifest/ui/settings.json`；
- 完整生产包：`Survivalcraft/shaderpacks/Dawnlight_v3.1/shaderpack.json` 及其
  `manifest/ui/settings.json`。当前 Dawnlight 是 `Authored`，43 个 option 全部由 43 个 control 覆盖。

示例是完整合法的 Manifest v3，可直接传给生产 loader 和本页第 9 节的 CLI。Empty/Auto 示例故意不放
`settings` 属性，也不复制 Dawnlight 的完整渲染图。

## 3. Authored 文档字段

UI 根对象只允许以下字段：

| 字段 | 类型 | 必需 | 缺省/约束 |
|---|---|---:|---|
| `schemaVersion` | integer | 是 | 当前只能为 `1` |
| `defaultLocale` | string | 是 | locale 回退目标 |
| `translations` | object | 否 | `{}`；locale 到 `key: text` 字典 |
| `pages` | array | 是 | 可为空，最多 32 页 |
| `hiddenOptions` | array | 否 | `[]`，最多 512 项 |

Page 字段：`id`、`title`、`groups` 必需；`order` 缺省 `0`；`visibleWhen` 缺省 `[]`。非空 page
至少有一个 group，每页最多 64 个 group。

Group 字段：`id`、`controls` 必需；`title` 可省略；`order` 缺省 `0`；`visibleWhen` 缺省 `[]`。
每个 group 至少有一个 control。

Control 字段：

| 字段 | 必需 | 缺省/说明 |
|---|---:|---|
| `id`、`option` | 是 | group 内唯一 ID；绑定存在的 canonical option ID |
| `widget` | 否 | `auto`；也可为 `toggle`、`choice`、`slider` |
| `label`、`description`、`unit`、`format` | 否 | 展示数据，不执行表达式或代码 |
| `step` | 否 | slider 步长，类型与 option 一致，必须大于零 |
| `min`、`max` | 否 | 必须成对出现，且为 Manifest 硬范围的子集 |
| `values` | choice 必需 | 与 Manifest `allowed` 集合精确相等，数组顺序决定显示顺序 |
| `advanced`、`developerOnly` | 否 | 均缺省 `false` |
| `visibleWhen`、`enabledWhen` | 否 | 均缺省 `[]`，同一数组内按 AND 组合 |

Choice 项只允许 `value` 和必需的 `label`。Hidden 项只允许 `option` 和必需的 `reason`。
Page/group/control/choice/condition 数组保留 authored 顺序；`order` 合法范围是
`-1,000,000..1,000,000`。

## 4. Widget 与 option 类型

| Widget | 可绑定类型 | 额外要求 |
|---|---|---|
| `toggle` | boolean | 不允许 `values`、`step`、`min`、`max` |
| `choice` | string、integer | Manifest 必须有 `allowed`；`values` 精确覆盖且不重复 |
| `slider` | integer、number | Manifest 必须有 `min/max`；显示范围不能扩大硬范围 |
| `auto` | boolean；带 `allowed` 的 string/integer；带范围的 integer/number | 不允许 widget 专属字段，由宿主确定控件 |

UI 不能重声明 option 的类型、默认值、allowed、硬范围或 invalidation impact；这些语义只来自根
Manifest option schema。

## 5. 精确覆盖与 Condition DAG

每个 Manifest option 必须恰好出现一次：要么绑定一个 control，要么列入一个 `hiddenOptions` 项。
因此合法文档始终满足：

```text
controls + hidden = options
```

遗漏、重复 control、重复 hidden、同一 option 同时可见和隐藏都以 `P9UI201` 拒绝。

Condition 只允许 `option` 加上 `equals`、`notEquals`、`in` 三者之一。比较值必须与被引用 option
同类型，并通过 allowed/硬范围校验；`in` 非空且值不重复。Page condition 影响页下全部控件，group
condition 影响组下全部控件，control 可分别控制可见性和可用性。

Loader 建立“受控 option -> 条件依赖 option”的有向图。自依赖或任意跨页、跨组的环都会以
`P9UI203` 拒绝，所以显示状态总能按稳定拓扑顺序求值。

## 6. 翻译回退

`translations` 的 locale 匹配不区分大小写，翻译 key 区分大小写。存在任意翻译表时，必须包含
`defaultLocale`。文本解析顺序固定为：

1. 当前 locale；
2. `defaultLocale`；
3. 调用者 fallback（通常为 option display name 或原始 value）；
4. key 本身。

缺少单个 key 会正常回退，不会使包加载失败。

## 7. 路径、文本和数量限制

`settings` 必须是规范化后不超过 256 字符、以 `.json` 结尾的包内相对路径。拒绝绝对路径、盘符、
空段、`.`、`..`、首尾空白、目录、缺失文件、根 Manifest 自引用，以及最终逃出包根的 symlink /
reparse point。UI JSON 最大 1 MiB。

| 项目 | 上限 |
|---|---:|
| page | 32 |
| group / page | 64 |
| control / document | 512 |
| choice / control | 256 |
| condition / owner | 16 |
| condition value | 256 |
| condition / document | 4096 |
| hidden option | 512 |
| locale 数 / 文档 | 32 |
| translation / locale | 2048 |
| translation / document | 8192 |
| local ID | 64 字符 |
| 一般短文本 | 256 字符 |
| description、translation、reason | 4096 字符 |

Local ID 首字符必须是小写 ASCII 字母或数字，其余允许小写字母、数字、`.`、`_`、`-`。JSON
允许注释和尾逗号，但所有层级拒绝重复属性，已定义结构拒绝未知属性。Locale ID 长度为 1–35，
只允许 ASCII 字母、数字和 `-`。

## 8. 诊断代码

错误文本包含 pack ID、相对 source、JSON path 和稳定代码：

| Code | 含义 |
|---|---|
| `P9UI001` | 根 `settings` 不是字符串 |
| `P9UI002` | settings 路径语法或规范化错误 |
| `P9UI003` | 缺失、目录或指回根 Manifest |
| `P9UI004` | 包根或最终 link 目标逃逸、link 解析失败 |
| `P9UI005` | UI 文件检查或读取失败 |
| `P9UI006` | UI 文件大小超限 |
| `P9UI007` | JSON 语法错误 |
| `P9UI100` | 重复属性、ID、locale 或 value |
| `P9UI101` | 未知属性 |
| `P9UI102` | 缺少必需属性 |
| `P9UI103` | JSON 或 option value 类型错误 |
| `P9UI104` | 数量或字符串长度超限 |
| `P9UI105` | 枚举、形状、order 或 domain invariant 错误 |
| `P9UI200` | option ID 非法或引用不存在 |
| `P9UI201` | option control/hidden 精确覆盖错误 |
| `P9UI202` | widget、choice、范围、step 或比较值不兼容 |
| `P9UI203` | condition 依赖环 |

不得解析异常自然语言来判断错误类型；工具和测试应使用稳定代码，向用户显示时保留 loader 原文。

## 9. 校验 CLI

从仓库根运行：

```powershell
dotnet run --project .\tools\ShaderPackCli\ShaderPackCli.csproj -- settings validate <pack-root>
```

CLI 直接调用生产 `ShaderPackManifestLoader.LoadExternal` 和内置 catalog snapshot，不维护第二套 parser。
输入是光影包根目录，不是单独的 `settings.json`。

退出码：

| Code | 含义 |
|---:|---|
| `0` | Manifest、settings UI 与内置 catalog 全部有效 |
| `1` | loader、IO 或验证失败；stderr 原样输出异常 message |
| `2` | 命令用法错误 |

成功输出顺序稳定、无时间戳和绝对路径：

```text
valid=true
packId=dawnlight:dawnlight_v3_1
schemaOrigin=Authored
settingsSource=manifest/ui/settings.json
settingsSha256=...
manifestSha256=...
options=43
pages=7
groups=13
controls=43
hidden=0
coverage=43/43
diagnostics=0
```

如有非致命 Manifest diagnostic，则在 `diagnostics` 后按稳定顺序输出 `diagnostic=...` 行。

## 10. UI hash 与 render hash

`SettingsUiCanonicalSha256` 只标识有效 Authored UI：忽略空白、注释和对象属性顺序，保留影响呈现的
数组顺序。Empty/Auto 的 UI hash 为空。修改翻译、控件顺序或 condition 会改变 UI hash。

`ManifestCanonicalSha256` 标识 metadata、options、resources、passes、programs 的规范化渲染
Manifest。根 `settings` 路径和 UI 内容不进入 render hash。纯 UI 改动不应执行 ManifestParity approve，
也不会仅因 UI hash 变化而重建 GPU generation。

## 11. 从硬编码菜单升级

迁移旧 C# 光影设置时按以下顺序进行，避免先删数据再失去导入能力：

1. 在 Manifest `options` 声明 canonical ID、类型、默认值、约束和 impact；
2. 用 Manifest program define、pass condition、resource 或运行时 option view 消费该 option；
3. 先用 Auto 验证完整 option surface，再加入 Authored `settings`、翻译、条件与 hidden 理由；
4. 从旧 `Settings.db` 捕获值并转换为 canonical option override；
5. 发布候选 generation，持久化 `options.json` 和 migration version marker（迁移版本标记）；只有 marker 确认 durable 后才精确
   清理旧 shader key，宿主 key 与未知非 shader key 必须保留；
6. 删除旧 C# Div、Read/Write bridge、重复翻译和冗余事件绑定；保留迁移 importer/version marker；
7. 用 CLI、无 GL 测试、BuiltIn/Dawnlight 连续切换和实机菜单验收确认生命周期稳定。

## 12. JSON 与可信 C# 的边界

JSON 可以：声明 option 和 UI option binding；通过 Manifest 声明和选择 program、pass、resource、
draw buffer、texture binding 及其数据依赖。它不能注册或调用任意类、方法或 callback，也不能获得
文件系统、网络或宿主任意代码执行能力。

CPU 侧算法、宿主副作用、GPU 对象创建/销毁、工厂和 Service 生命周期必须由可信 Mod/C# 注册，
并保持 generation-owned C# 所有权。自定义 Mod 若增加 stage/service/semantic/engine-draw provider 或
capability catalog，应先构造完整 `PipelineCatalogSnapshot`，再调用
`ShaderPackManifestLoader.LoadExternal(selection, packRoot, catalogs)` overload；不能靠 JSON 注册 C#
类、方法或 callback。

实现与阶段历史详见 `docs/P9.1 Shader Pack Settings UI Schema.md`，最终验收要求见
`docs/P9 Shader Pack Settings Menu Plan.md`。
