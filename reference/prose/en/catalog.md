## Behavior and constraints {#behavior}

These collections come from pinned Catalog v2 and v5 completion. Metadata retains dependencies, frequencies, spaces, formats and target/state restrictions. Match exact ID/version pairs. A field or registration does not prove an executable Provider, device support or actual game execution. Missing units/spaces remain missing rather than being guessed from names.

stageTemplates names creation entry points; services describes trusted resource/lifecycle support; semantics describes numeric uniforms; engineDrawProviders names host draws; capabilities captures build values. The scene collections jointly freeze categories, Providers, vertices, system bindings and fallback. Keep different versions of the same ID distinct.

Catalog.hash, sceneAbiHash and dataAbiHash identify separate projections. Historical supportedFormats.manifest=[3,4] does not override validated v5 Schema/Loader support. Preserve the exported metadata and explain that discrepancy in compatibility. The completion's dataAbiCatalog is authoritative for all 23 inputs, function arities and its published budgets.

Exports contain public contracts rather than host callbacks, private methods, shader source or native objects. JSON selects published capabilities; it cannot add a Service, call arbitrary C# or enlarge GL limits.
